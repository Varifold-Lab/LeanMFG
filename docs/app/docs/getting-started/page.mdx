# Installation

LeanMFG requires Lean 4.34.0. Install [elan](https://github.com/leanprover/elan), which selects the toolchain recorded by a Lean project. The numerical library runs on the CPU and does not require Python.

## Install the library

<Tabs labels={['Repository checkout', 'Existing Lake project']}>
<section>

Use a repository checkout to run the command-line solver and examples. These commands select the source commit used for this documentation:

<CodeBlock language="sh" code={`git clone https://github.com/Varifold-Lab/LeanMFG.git\ncd LeanMFG\ngit checkout ${buildInfo.commit}\nlake exe cache get\nlake build LeanMFG mfglib mfglib_check`} />

The cache command downloads compiled mathlib artifacts. The first build also compiles the required FloatLib modules.

</section>
<section>

Use the matching `lean-toolchain` in your project:

```text
leanprover/lean4:v4.34.0
```

Add LeanMFG to your `lakefile.toml`:

<CodeBlock language="toml" code={`[[require]]\nname = "leanmfg"\ngit = "https://github.com/Varifold-Lab/LeanMFG.git"\nrev = "${buildInfo.commit}"`} />

Resolve and build the dependencies:

```sh
lake update
lake exe cache get
lake build
```

Commit the generated `lake-manifest.json`. Use the selected LeanMFG commit's mathlib and FloatLib versions together.

</section>
</Tabs>

## Check an import

This example uses a proved equilibrium statement:

```lean
import LeanMFG

example : LeanMFG.RPS.IsEquilibrium LeanMFG.RPS.uniform :=
  LeanMFG.RPS.uniform_equilibrium
```

For numerical code, use `import LeanMFG.Computational`. The <RepositoryLink path="tests/downstream/Main.lean">downstream client</RepositoryLink> exercises both interfaces in a fresh Lake project during CI.

## Run a solver

From a repository checkout:

```sh
lake exe mfglib left_right omd 20
```

Continue with [Run a first solver](/docs/quickstart) to read the output and call the solver from Lean.

## Dependency changes

The package's Lean toolchain and dependency commits form a tested combination. When upgrading LeanMFG, update the toolchain and resolve the dependency manifest together. The [release guide](/docs/releases) describes compatibility changes between versions.
