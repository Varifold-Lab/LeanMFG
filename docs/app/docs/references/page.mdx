# Related work and references

## Software

- [MFGLib](https://github.com/radar-research-lab/MFGLib) is a Python library for defining and solving mean field games. Its scope is useful when planning executable LeanMFG examples. Its rock-paper-scissors environment uses a different reward rule from LeanMFG's static case.
- [LeanSort](https://github.com/Varifold-Lab/LeanSort) informed the initial separation of models, algorithms, and proofs.
